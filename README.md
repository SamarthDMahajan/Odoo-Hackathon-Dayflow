# 🚀 Dayflow HRMS - Enterprise Leave & Attendance Management

Dayflow is a full-stack, role-based Human Resource Management System built to streamline daily employee attendance tracking and administrative leave approvals. Designed with a clean, responsive UI and a robust relational database architecture.

## ✨ Key Features

### 🏢 Admin / HR Capabilities
* **Dynamic Analytics Dashboard:** Real-time metrics tracking total workforce, daily presence, and pending leave requests.
* **Employee Directory:** Secure, real-time view of all registered personnel and their roles.
* **Leave Management Portal:** Approve or reject employee leave requests with status color-coding.
* **Data Export API:** One-click generation and download of complete attendance reports in `.csv` format for payroll and auditing.

### 👤 Employee Capabilities
* **Secure Authentication:** Encrypted session management and role-based access control.
* **Daily Attendance Tracking:** Intuitive Check-In and Check-Out system.
* **Leave Applications:** Apply for Sick, Casual, or Paid leave with specific date ranges and automated status tracking.

## 🛠️ Technology Stack
* **Backend:** Python, Flask, Flask-SQLAlchemy
* **Database:** SQLite (Relational Data Modeling)
* **Frontend:** HTML5, Jinja2 Templating, Tailwind CSS
* **Architecture:** MVC Pattern, RESTful API Routes
