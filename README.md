# 🚀 Dayflow HRMS - Enterprise Leave & Attendance Management

Dayflow is a full-stack, role-based Human Resource Management System built to streamline daily employee attendance tracking, administrative leave approvals, payroll computation, and enterprise auditing. Designed with a clean, responsive UI and a robust relational database architecture.

## ✨ Key Features

### 🏢 Admin / HR Capabilities
* **Dynamic Analytics Dashboard:** Real-time metrics tracking total workforce, daily presence, and pending leave requests with a live system status ticker.
* **Automated Payroll System:** One-click payroll generation calculating gross pay, deductions, and net salary based on verified attendance data.
* **Security Audit Logs:** Immutable system logs tracking critical actions (logins, check-ins, leave approvals) to ensure enterprise-grade accountability.
* **Employee Directory & Live Search:** Secure, real-time view of all registered personnel with instant client-side filtering.
* **Leave Management Portal:** Approve or reject employee leave requests with status color-coding.
* **Data Export API:** One-click generation and download of complete attendance reports in `.csv` format.

### 👤 Employee Capabilities
* **Secure Authentication & Profiles:** Encrypted session management, role-based access control, and dedicated employee profile cards.
* **Daily Attendance Tracking:** Intuitive Check-In and Check-Out system.
* **Leave Applications:** Apply for Sick, Casual, or Paid leave with specific date ranges and automated status tracking.

### 🧪 Evaluator / Judge Features
* **One-Click Demo Login:** A built-in evaluator shortcut on the login page to instantly auto-fill admin credentials for zero-friction testing.

## 🛠️ Technology Stack
* **Backend:** Python, Flask, Flask-SQLAlchemy
* **Database:** SQLite (Relational Data Modeling)
* **Frontend:** HTML5, Jinja2 Templating, Tailwind CSS, JavaScript
* **Architecture:** MVC Pattern, RESTful API Routes
